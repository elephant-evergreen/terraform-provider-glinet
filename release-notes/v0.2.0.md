## Breaking changes

- Remove the per-rule `glinet_firewall_rule` resource and its `position` attribute. Use the singleton `glinet_firewall_rules` ordered policy.
- Stop reading the legacy `home_iac_owner` marker. Only `terraform_owner` marks provider-managed sections.

## Upgrade notes

1. Upgrade to 0.1.6 and import `glinet_firewall_rules` while the per-rule resource is still available.
2. Remove the old `glinet_firewall_rule` state entries and confirm a no-change plan.
3. Run `scripts/migrate-ownership-marker.sh` as root on the router with a tested wired recovery connection and an encrypted backup. It moves every legacy marker, removes the old option, commits the packages, and fails if any legacy marker remains.
4. Apply 0.2.0 only after the migration reports no remaining legacy markers and the plan is no-change.

Do not upgrade directly from 0.1.5 or earlier. The ordered policy and the marker migration must be complete first.
