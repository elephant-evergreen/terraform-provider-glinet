## Upgrade notes

Existing configurations and state need no changes.

- The provider treats firmware 4.11.x in router mode as one verified line. It no longer warns about individual patches, so a new 4.11.x release does not need a provider release before users can run it without a warning.

## Fixes

- Remove the per-patch firmware warning and the list of verified builds from the provider. The router checks still require the Flint 2 model, firmware 4.11.x, and router mode.

## Compatibility

The 4.11 line was exercised across patches, including the upgrade path, clean plans, firewall and forwarding changes, a declared redirect, a failed verification with rollback, router-side recovery after an SSH disconnection, and reboot. Traffic acceptance across each network and power-loss recovery remain separate manual checks.
