## Upgrade notes

Existing configurations and state need no changes.

## Compatibility

- The provider now accepts stable `4.11.x` firmware instead of requiring exactly `4.11.0`. Pre-release and unknown builds remain unsupported.
- Firmware `4.11.0` remains the hardware-verified build.
- Stable `4.11.x` patches above `4.11.0` are allowed with a warning but are not hardware-verified in this release.

## Fixes

- Replace the exact `4.11.0` preflight check with a stable `4.11.x` gate. Plan, read, and apply use the same gate, so an unsupported build fails consistently and an untested patch produces a warning.

## Hardware status

Fixture and Terraform protocol tests cover the firmware gate. Hardware acceptance is not included in this release.
