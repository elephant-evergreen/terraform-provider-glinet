## Upgrade notes

Existing configurations and state need no changes.

## Compatibility

- The provider now accepts stable `4.11.x` firmware instead of requiring exactly `4.11.0`. Pre-release and unknown builds remain unsupported.
- Firmware `4.11.0` remains the hardware-verified build. A stable `4.11.x` patch outside the verified set is allowed with a warning; update `testedFirmwares` only after the hardware acceptance checks pass.
- Firmware `4.11.1` support is allowed by the new policy but is not yet recorded as hardware-verified in this release. `4.11.1` is the vendor's minimum security version for this model; the verified-build distinction is not a recommendation to stay on `4.11.0`.

## Fixes

- Replace the exact `4.11.0` preflight check with a stable `4.11.x` gate. Plan, read, and apply use the same gate, so an unsupported build fails consistently and an untested patch produces a warning.

## Hardware status

Fixture and Terraform protocol tests cover the firmware gate. Hardware acceptance is not included in this release; record the exact firmware and provider version in the hardware verification notes when it is performed.
